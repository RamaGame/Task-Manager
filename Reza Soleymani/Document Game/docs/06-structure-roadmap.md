# ساختار پوشه‌ها و نقشه‌ی راه

## ساختار پیشنهادی پروژه
```text
Tactical Battles/
├── README.md                 # فهرست مرکزی و لینک‌ها
├── docs/                     # سندهای جداگانه‌ی طراحی
├── images/                   # تصاویر مفهومی مشترک
├── Untitled/                 # یادداشت‌های اولیه
└── Untitled 1/               # سند قبلی مقر فرماندهی
```

فایل‌های هر بخش جدا هستند و از `README.md` به هم لینک شده‌اند. تصاویر در پوشه‌ی مشترک `images` قرار دارند تا کپی تکراری ساخته نشود.

## نقشه‌ی راه پیشنهادی
1. **نمونه‌ی نبرد:** دوربین ایزومتریک، استقرار سربازها، حرکت و شلیک خودکار، یک دشمن و یک ماموریت.
2. **فرماندهی تاکتیکی:** هدف‌گیری پشتیبانی، پهپاد، بمب و موشک با محدودیت/بازیابی.
3. **پیشرفت:** سربازها، سلاح‌ها و مسیرهای ارتقای ۱۶ سطحی، پاداش و ذخیره‌ی پیشرفت.
4. **هاب و منوها:** پروفایل، ماموریت‌ها، جایزه‌ی روزانه و رابط ارتقا.
5. **محتوای رقابتی/اجتماعی:** لیدربرد، چت گلوبال و سیزن‌پس؛ پس از تثبیت حلقه‌ی بازی.

## موارد نیازمند تصمیم در طراحی
- آیا نبرد فقط تماشا و پشتیبانی است یا دستور حرکت/هدف هم داده می‌شود؟
- در شکست، سربازها چه وضعی پیدا می‌کنند؟
- منابع ارتقا چند نوع‌اند و از کجا به‌دست می‌آیند؟
- پشتیبانی‌ها شارژ زمانی دارند، مهمات محدود دارند یا هر دو؟
- لیدربرد و چت از روز اول لازم‌اند یا پس از انتشار اولیه؟
