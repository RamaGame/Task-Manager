# منوها و امکانات اجتماعی

## هاب اصلی
منوی اصلی نقش مقر فرماندهی را دارد و دسترسی به بخش‌ها، موجودی منابع، اعلان‌ها و دکمه‌ی واضح **Battle** را فراهم می‌کند.

## نقشه‌ی منو
- **گیم‌پلی / Battle** → آماده‌سازی گروه → انتخاب ماموریت → نبرد
- **جایزه‌ی روزانه** → تقویم پاداش و دریافت جایزه‌ی امروز
- **Leaderboard (لیدربرد)** → رتبه‌ی دوستان/جهانی و فصل جاری
- **ماموریت‌ها** → روزانه، هفتگی و داستانی؛ شرایط و پاداش هر ماموریت
- **ارتقاها** → سربازها، سلاح‌ها، مهارت‌ها و تجهیزات
- **Weapons (سلاح‌ها)** → فهرست، جزئیات، انتخاب و ارتقای سلاح
- **پروفایل** → نام و شناسه، آواتار، آمار، دستاوردها و تنظیمات حریم خصوصی
- **چت گلوبال** → گفت‌وگوی عمومی، گزارش و مسدودسازی کاربر، فیلتر پیام
- **Season Pass (سیزن‌پس)** → مسیر جایزه‌ی فصل، سطح فعلی و دریافت پاداش‌ها

## پروفایل
نمایش سطح فرمانده، تعداد نبردها، بردها، بهترین رکورد، سربازهای شاخص و نشان‌های کسب‌شده. تغییر نام/آواتار و تنظیمات قابل‌نمایش بودن اطلاعات از همین صفحه انجام می‌شود.

## چت گلوبال
چت باید پیام‌رسانی ساده و قابل‌مدیریت داشته باشد: فیلتر متن، محدودیت ارسال پشت‌سرهم، گزارش، مسدودسازی و کانال زبان/منطقه در صورت نیاز. جزئیات فنی و سیاست‌های انتشار پیش از پیاده‌سازی نهایی می‌شوند.

## اصول رابط
- مسیر بازگشت به هاب در همه‌ی زیرصفحه‌ها ثابت باشد.
- اعلان‌ها فقط برای رویدادهای قابل‌اقدام نمایش داده شوند.
- هزینه، شرط بازشدن و پاداش پیش از اقدام مشخص باشد.
- صفحات موبایل‌محور، خوانا و مناسب لمس طراحی شوند.
